# Background music

Drop royalty-free music files (`.mp3`, `.m4a`, `.wav`) in this folder.
The video worker picks one at random for each video and plays it quietly
under the AI voiceover (or a bit louder if there is no voiceover).

Free, YouTube-safe sources:
- YouTube Studio → **Audio Library** (choose tracks marked "No attribution required")
- Pixabay Music (pixabay.com/music)

Upbeat, instrumental tracks 30 seconds or longer work best; shorter tracks loop.
